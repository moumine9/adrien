adrien: architecture decision records

Architecture decisions for developers and their AI agents.

Adrien keeps your ADRs as plain markdown in your own git repos, and answers one question for people and agents alike: which decisions govern the code I am about to change, and why?

Read the docs Open the live demo

Install

npx adrien

Needs Node 22.13 or later. Prefer a global install? npm install -g adrien does the same.

Four surfaces, one log

Every surface reads the same ADR files from your repositories, so a decision you read in the web view is the one your agent is given.

  • mcp

    MCP server

    Hands an agent the decisions that govern a file before it edits, each with its one-line review rule. The agent can propose a decision. It can never accept one. 

    claude mcp add adrien -- npx -y adrien mcp

  • cli

    CLI

    Create the log, record a decision, and ask what governs a file. Add --json for scripts. 

    npx adrien initadrien for src/billing/invoice.ts

  • http

    HTTP API

    A small read-only JSON API on 127.0.0.1:4310, for scripts and dashboards. It refuses every write. 

    adrien servecurl http://127.0.0.1:4310/api/meta

  • web

    Web visualizer

    The decisions, their graph, the files they govern and the health check, on one page. The same adrien serve command serves it, and the demo shows it with sample data. 

    adrien serve

    Then open http://127.0.0.1:4310.
